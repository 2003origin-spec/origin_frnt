## The pair of equations

:::formula{title="General form"}
$$a_1x + b_1y + c_1 = 0$$
$$a_2x + b_2y + c_2 = 0$$
$a_1, b_1, c_1, a_2, b_2, c_2$ are real numbers. In each equation, the $x$ and $y$ coefficients are not both zero.

A **solution** is a pair of values $(x, y)$ that makes **both** equations true.
:::

:::formula{title="Graph of one equation"}
The graph of each equation is a **straight line**. Two points are enough to draw it.
$$\text{meets the } x\text{-axis where } y = 0$$
$$\text{meets the } y\text{-axis where } x = 0$$
:::

## Comparing the ratios

Write **both** equations in the same form first (both as $\ldots = 0$). The ratios below need $a_2, b_2, c_2 \ne 0$.

:::formula{title="Intersecting lines: one solution"}
$$\frac{a_1}{a_2} \ne \frac{b_1}{b_2}$$
Exactly one solution (unique). The pair is **consistent**.
:::

:::formula{title="Coincident lines: infinitely many solutions"}
$$\frac{a_1}{a_2} = \frac{b_1}{b_2} = \frac{c_1}{c_2}$$
Every point on the line is a solution. The pair is **dependent** (and so consistent).
:::

:::formula{title="Parallel lines: no solution"}
$$\frac{a_1}{a_2} = \frac{b_1}{b_2} \ne \frac{c_1}{c_2}$$
The lines never meet. The pair is **inconsistent**.
:::

:::formula{title="If a coefficient is zero"}
(beyond the Class 10 book) The ratio test for one solution can be written without division:
$$a_1b_2 - a_2b_1 \ne 0$$
This works even when some coefficient is 0.
:::

## Signs from the algebra

:::formula{title="What the last step tells you"}
After substituting or eliminating, if no variable is left:
- a **true** statement (like $18 = 18$) means **infinitely many** solutions;
- a **false** statement (like $0 = 9$) means **no** solution.
:::

## Writing a line on purpose

:::formula{title="Lines related to ax + by + c = 0"}
Multiply by any $k \ne 0$:
$$kax + kby + kc = 0$$
This is the **same line** (coincident).
$$kax + kby + d = 0$$
If $d \ne kc$, this is a **parallel** line. Any line whose $x$ and $y$ coefficients are not in the ratio $a : b$ **intersects** it.
:::

## Set-ups for word problems

:::formula{title="Two-digit number"}
Tens digit $x$, units digit $y$:
$$\text{number} = 10x + y$$
$$\text{digits reversed} = 10y + x$$
:::

:::formula{title="Ages"}
Present age $x$:
$$n \text{ years ago} = x - n$$
$$n \text{ years from now} = x + n$$
The **difference** between two people's ages never changes.
:::

:::formula{title="Fraction"}
$$\text{fraction} = \frac{x}{y} \quad (y \ne 0)$$
Adding 2 to both parts gives $\dfrac{x + 2}{y + 2}$. Clear the fractions (multiply both sides by both denominators) to make it linear.
:::

:::formula{title="Fixed charge plus a rate"}
$$\text{total} = \text{fixed charge} + \text{rate} \times \text{units}$$
Used for taxi fares, library charges and phone bills. Count only the units that are charged at the rate. Example: if the fixed charge covers the first 3 days, a book kept 7 days has 4 extra days.
:::

:::formula{title="Money and shapes"}
$$\text{saving} = \text{income} - \text{expenditure}$$
$$\text{half the perimeter} = l + b$$
$$\text{supplementary angles: } x + y = 180^\circ$$
:::
