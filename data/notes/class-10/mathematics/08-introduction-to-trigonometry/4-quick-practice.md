## Ratios from a right triangle

:::question{title="1. From two sides" exam="Board level"}
In triangle ABC, right-angled at B, $AB = 12$ cm and $BC = 5$ cm. Find $\sin A$, $\cos A$ and $\tan C$.

---

$AC = \sqrt{144 + 25} = 13$ cm.

$\sin A = \dfrac{BC}{AC} =$ **$\dfrac{5}{13}$**, $\cos A = \dfrac{AB}{AC} =$ **$\dfrac{12}{13}$**.

For angle C the opposite side is AB: $\tan C = \dfrac{AB}{BC} =$ **$\dfrac{12}{5}$**.
:::

:::question{title="2. One ratio given" exam="Board level"}
If $\sin A = \dfrac{8}{17}$, find $\cos A$ and $\tan A$.

---

Opposite $= 8k$, hypotenuse $= 17k$. Adjacent $= \sqrt{289k^2 - 64k^2} = 15k$.

$\cos A =$ **$\dfrac{15}{17}$** and $\tan A =$ **$\dfrac{8}{15}$**.
:::

:::question{title="3. From cot" exam="Board level"}
Given $7\cot\theta = 24$, find $\sin\theta$ and $\sec\theta$.

---

$\cot\theta = \dfrac{24}{7}$: adjacent $= 24k$, opposite $= 7k$, hypotenuse $= \sqrt{576k^2 + 49k^2} = 25k$.

$\sin\theta =$ **$\dfrac{7}{25}$** and $\sec\theta =$ **$\dfrac{25}{24}$**.
:::

:::question{title="4. Difference of two sides" exam="Board level"}
In triangle PQR, right-angled at Q, $PQ = 8$ cm and $PR - QR = 4$ cm. Find $\sin P$ and $\cos P$.

---

$PR = QR + 4$. By Pythagoras, $(QR + 4)^2 = 64 + QR^2$, so $8\,QR + 16 = 64$ and $QR = 6$ cm. Then $PR = 10$ cm.

$\sin P = \dfrac{QR}{PR} =$ **$\dfrac35$** and $\cos P = \dfrac{PQ}{PR} =$ **$\dfrac45$**.
:::

## Specific angles

:::question{title="5. Evaluate" exam="Board level"}
Evaluate $4\sin^2 60^\circ + 3\tan^2 30^\circ - 8\sin 45^\circ \cos 45^\circ$.

---

$4 \times \dfrac34 + 3 \times \dfrac13 - 8 \times \dfrac{1}{\sqrt2} \times \dfrac{1}{\sqrt2} = 3 + 1 - 4 =$ **0**.
:::

:::question{title="6. A fraction" exam="Board level"}
Evaluate $\dfrac{N}{D}$, where

$$N = \tan^2 60^\circ + 4\cos^2 45^\circ + 3\sec^2 30^\circ$$

$$D = \operatorname{cosec} 30^\circ + \sec 60^\circ - \cot^2 30^\circ$$

---

$N = 3 + 4 \times \dfrac12 + 3 \times \dfrac43 = 3 + 2 + 4 = 9$.

$D = 2 + 2 - 3 = 1$. So $\dfrac{N}{D} =$ **9**.
:::

:::question{title="7. Find the sides" exam="Board level"}
In triangle ABC, right-angled at B, $AC = 12$ cm and $\angle A = 60^\circ$. Find AB and BC.

---

$AB = AC\cos 60^\circ = 12 \times \dfrac12 =$ **6 cm**.

$BC = AC\sin 60^\circ = 12 \times \dfrac{\sqrt3}{2} =$ **$6\sqrt3$ cm** (about 10.39 cm).
:::

:::question{title="8. Find the angles" exam="Board level"}
If $\sin(A + B) = 1$ and $\cos(A - B) = \dfrac{\sqrt3}{2}$, with $0^\circ < A + B \le 90^\circ$ and $A > B$, find A and B.

---

$\sin(A + B) = 1$ gives $A + B = 90^\circ$. $\cos(A - B) = \dfrac{\sqrt3}{2}$ gives $A - B = 30^\circ$.

Adding: $2A = 120^\circ$. So **$A = 60^\circ$, $B = 30^\circ$**.
:::

## Identities

:::question{title="9. Prove it" exam="Board level"}
Prove that $\sec^4 A - \sec^2 A = \tan^4 A + \tan^2 A$.

---

LHS $= \sec^2 A\,(\sec^2 A - 1) = (1 + \tan^2 A)\tan^2 A$.

$= \tan^2 A + \tan^4 A =$ **RHS**. Proved.
:::

:::question{title="10. sec + tan" exam="Board level"}
If $\sec\theta + \tan\theta = 3$, find $\sin\theta$.

---

$(\sec\theta + \tan\theta)(\sec\theta - \tan\theta) = \sec^2\theta - \tan^2\theta = 1$, so $\sec\theta - \tan\theta = \dfrac13$.

Adding the two equations: $2\sec\theta = \dfrac{10}{3}$, so $\sec\theta = \dfrac53$. Subtracting: $\tan\theta = \dfrac43$.

$\sin\theta = \dfrac{\tan\theta}{\sec\theta} = \dfrac43 \times \dfrac35 =$ **$\dfrac45$**.
:::
