Take $\pi = \dfrac{22}{7}$ unless the question says otherwise. Some NCERT examples use $\pi = 3.14$. Use the value the question gives.

## The basic solids (from earlier classes)

$r$ = radius, $h$ = height, $l$ = slant height. Areas in cm² or m², volumes in cm³ or m³.

:::formula{title="Cuboid"}
$$\text{TSA} = 2(lb + bh + hl)$$
$$V = l \times b \times h$$
Here $l$, $b$, $h$ = length, breadth and height.
:::

:::formula{title="Cube"}
$$\text{TSA} = 6a^2$$
$$V = a^3$$
$a$ = edge.
:::

:::formula{title="Cylinder"}
$$\text{CSA} = 2\pi r h$$
$$\text{TSA} = 2\pi r(r + h)$$
$$V = \pi r^2 h$$
TSA counts both circular ends.
:::

:::formula{title="Cone"}
$$l = \sqrt{r^2 + h^2}$$
$$\text{CSA} = \pi r l$$
$$\text{TSA} = \pi r(l + r)$$
$$V = \frac{1}{3}\pi r^2 h$$
CSA uses the **slant height** $l$. Volume uses the **height** $h$.
:::

:::formula{title="Sphere"}
$$\text{SA} = 4\pi r^2$$
$$V = \frac{4}{3}\pi r^3$$
:::

:::formula{title="Hemisphere"}
$$\text{CSA} = 2\pi r^2$$
$$\text{TSA} = 3\pi r^2$$
$$V = \frac{2}{3}\pi r^3$$
TSA = curved part + flat circle ($\pi r^2$).
:::

:::formula{title="Half cylinder (shed roof)"}
$$V = \frac{1}{2}\pi r^2 h$$
$h$ = its length. Used in NCERT's shed example.
:::

## Combining solids: the two rules

:::formula{title="Surface area of a combination"}
$$\text{SA} = \text{sum of the visible surfaces}$$
Add only the faces you can still see and touch. Faces that are stuck together or hidden are left out.
:::

:::formula{title="Volume of a combination"}
$$V = V_1 + V_2 \quad \text{(joined)}$$
$$V = V_1 - V_2 \quad \text{(cut out)}$$
:::

## Common shapes in the book

:::formula{title="Capsule: cylinder with two hemispherical ends"}
$$\text{SA} = 2\pi r h + 4\pi r^2$$
$$V = \pi r^2 h + \frac{4}{3}\pi r^3$$
$h$ = length of the cylinder part only = total length $- 2r$.
:::

:::formula{title="Toy: cone on a hemisphere (same radius)"}
$$\text{SA} = \pi r l + 2\pi r^2$$
$$V = \frac{1}{3}\pi r^2 h + \frac{2}{3}\pi r^3$$
$h$ = height of the cone = total height $- r$.
:::

:::formula{title="Tent: cone on a cylinder (no floor)"}
$$\text{Canvas} = 2\pi r h + \pi r l$$
Add $\pi r^2$ only if the floor is also covered.
:::

:::formula{title="Hemisphere on a cube, or hollowed out of a cube"}
$$\text{SA} = 6a^2 + \pi r^2$$
$a$ = edge of the cube, $r$ = radius of the hemisphere ($r \le a/2$). It comes from $6a^2 - \pi r^2 + 2\pi r^2$. Both cases give the same answer. The greatest possible hemisphere has diameter $= a$.
:::

:::formula{title="Cone hollowed out of a cylinder (same r and h)"}
$$\text{SA} = 2\pi r h + \pi r^2 + \pi r l$$
One flat end is left; the other is replaced by the inside of the cone.
:::

:::formula{title="Hemisphere scooped from each end of a cylinder"}
$$\text{SA} = 2\pi r h + 4\pi r^2$$
The hemispheres have the same radius $r$ as the cylinder. Here $h$ is the **full** height of the cylinder (nothing is subtracted). The two flat ends are replaced by two curved bowls.
:::

## Units

:::formula{title="Conversions"}
$$1\ \text{m} = 100\ \text{cm}$$
$$1\ \text{m}^2 = 10\,000\ \text{cm}^2$$
$$1\ \text{m}^3 = 10^6\ \text{cm}^3$$
$$1\ \text{litre} = 1000\ \text{cm}^3$$
Change every length to the **same unit** before you start.
:::
