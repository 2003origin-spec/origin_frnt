## Distance formula

:::question{title="1. A distance" exam="Board level"}
Find the distance between the points $(-3, 4)$ and $(5, -2)$.

---

$d = \sqrt{(5 + 3)^2 + (-2 - 4)^2} = \sqrt{64 + 36} = \sqrt{100} =$ **10 units**.
:::

:::question{title="2. Two values" exam="Board level"}
The distance between $P(3, k)$ and $Q(-1, 2)$ is 5 units. Find all the values of $k$.

---

$(3 + 1)^2 + (k - 2)^2 = 25$, so $(k - 2)^2 = 9$ and $k - 2 = 3$ or $-3$.

**$k = 5$ or $k = -1$.**
:::

:::question{title="3. Type of triangle" exam="Board level"}
Show that $A(1, 1)$, $B(4, 5)$ and $C(8, 2)$ are the vertices of a triangle, and name its type.

---

$AB^2 = 3^2 + 4^2 = 25$, $BC^2 = 4^2 + (-3)^2 = 25$, $AC^2 = 7^2 + 1^2 = 50$.

So $AB = BC = 5$ and $AC = 5\sqrt2 \approx 7.07$. Since $5 + 5 > 7.07$, the points form a triangle.

$AB^2 + BC^2 = 50 = AC^2$, so $\angle B = 90^\circ$. It is an **isosceles right triangle** (right-angled at $B$).
:::

:::question{title="4. Collinear points" exam="Board level"}
Check whether $A(-2, -5)$, $B(1, 1)$ and $C(3, 5)$ are collinear.

---

$AB = \sqrt{9 + 36} = 3\sqrt5$, $BC = \sqrt{4 + 16} = 2\sqrt5$, $AC = \sqrt{25 + 100} = 5\sqrt5$.

$AB + BC = 5\sqrt5 = AC$, so the points are **collinear** ($B$ lies between $A$ and $C$).
:::

:::question{title="5. Point on the x-axis" exam="Board level"}
Find the point on the $x$-axis that is equidistant from $A(1, 5)$ and $B(7, 1)$.

---

Let the point be $P(x, 0)$. Then $PA^2 = PB^2$:

$(x - 1)^2 + 25 = (x - 7)^2 + 1$

$-2x + 26 = -14x + 50$, so $12x = 24$ and $x = 2$.

The point is **$(2, 0)$**. (Check: $PA = PB = \sqrt{26}$.)
:::

## Section formula

:::question{title="6. Dividing a segment" exam="Board level"}
Find the point that divides the join of $A(-2, 3)$ and $B(8, -7)$ internally in the ratio $2 : 3$.

---

$x = \dfrac{2(8) + 3(-2)}{5} = \dfrac{10}{5} = 2$

$y = \dfrac{2(-7) + 3(3)}{5} = \dfrac{-5}{5} = -1$

The point is **$(2, -1)$**.
:::

:::question{title="7. Cut by the x-axis" exam="Board level"}
Find the ratio in which the $x$-axis divides the join of $A(3, -4)$ and $B(-3, 8)$. Also find the point of division.

---

Let the ratio be $k : 1$. On the $x$-axis, $y = 0$:

$\dfrac{8k - 4}{k + 1} = 0$, so $k = \dfrac12$. The ratio is **$1 : 2$**.

$x = \dfrac{\frac12(-3) + 3}{\frac32} = \dfrac{\frac32}{\frac32} = 1$. The point is **$(1, 0)$**.
:::

:::question{title="8. End of a diameter" exam="Board level"}
The centre of a circle is $C(1, -2)$. One end of a diameter is $A(-3, 4)$. Find the other end $B$.

---

$C$ is the mid-point of $AB$:

$\dfrac{-3 + x}{2} = 1$ gives $x = 5$. $\dfrac{4 + y}{2} = -2$ gives $y = -8$.

So **$B = (5, -8)$**.
:::

:::question{title="9. Fourth vertex" exam="Board level"}
$A(1, 2)$, $B(5, 3)$, $C(6, 7)$ and $D(x, y)$ are the vertices of a parallelogram, taken in order. Find $D$.

---

The diagonals $AC$ and $BD$ bisect each other, so their mid-points are equal:

$\dfrac{1 + 6}{2} = \dfrac{5 + x}{2}$ gives $x = 2$. $\dfrac{2 + 7}{2} = \dfrac{3 + y}{2}$ gives $y = 6$.

So **$D = (2, 6)$**.
:::

:::question{title="10. Unknown ratio and coordinate" exam="Board level"}
The point $P(x, 2)$ lies on the segment joining $A(12, 5)$ and $B(4, -3)$. Find the ratio $AP : PB$ and the value of $x$.

---

Let the ratio be $k : 1$. Use the $y$-coordinate:

$\dfrac{-3k + 5}{k + 1} = 2$, so $-3k + 5 = 2k + 2$ and $k = \dfrac35$. The ratio is **$3 : 5$**.

$x = \dfrac{3(4) + 5(12)}{3 + 5} = \dfrac{72}{8} =$ **9**.
:::
