## The cell cycle in numbers

:::formula{title="How long it takes"}
- Human cells in culture: one cycle in about **24 hours**.
- Of this, cell division proper (M phase) lasts only about **1 hour**.
- Interphase takes **more than 95%** of the cycle.
- Yeast: one cycle in only about **90 minutes**.

The length of the cycle varies between organisms and between cell types.
:::

:::formula{title="Order of the phases"}
$$G_1 \to S \to G_2 \to M$$
Interphase = $G_1$ + S + $G_2$. M phase = karyokinesis (prophase, metaphase, anaphase, telophase) + cytokinesis.

Cells that stop dividing leave $G_1$ and enter $G_0$ (quiescent stage).
:::

:::formula{title="What S phase changes"}
$$\text{DNA: } 2C \to 4C$$
$$\text{Chromosomes: } 2n \to 2n$$
DNA content doubles, but the chromosome number stays the same. Each chromosome now has **two sister chromatids** held at one centromere.
:::

## How to count

$C$ = DNA content. NCERT calls the $G_1$ amount of a diploid cell $2C$. $n$ = chromosomes in one haploid set, so a diploid cell has $2n$.

:::formula{title="Counting rules"}
- **Chromosomes:** count the centromeres.
- **Chromatids:** 2 per chromosome from S phase until the centromere splits; 1 per chromosome otherwise.
- **DNA:** doubles only in S phase. It halves only when a cell splits into two (cytokinesis).
:::

:::trap
At **anaphase** of mitosis, the centromeres split, so the chromosome number per cell doubles for a short time ($2n \to 4n$; a count only, the cell is not tetraploid), while DNA stays $4C$. Chromosome number and DNA content do **not** change together.
:::

## Mitosis count table

For a diploid cell with $2n$ chromosomes and $2C$ DNA in $G_1$.

| Stage | Chromosomes | Chromatids each | DNA |
| --- | --- | --- | --- |
| $G_1$ | $2n$ | 1 | $2C$ |
| S | $2n$ | 1 → 2 | $2C$ → $4C$ |
| $G_2$ | $2n$ | 2 | $4C$ |
| Prophase | $2n$ | 2 | $4C$ |
| Metaphase | $2n$ | 2 | $4C$ |
| Anaphase | $4n$ | 1 | $4C$ |
| Telophase | $2n$ per nucleus, two nuclei | 1 | $4C$ in the cell |
| Each daughter cell | $2n$ | 1 | $2C$ |

:::example
Onion root tip cells have 16 chromosomes ($2n = 16$). Say the DNA is $2C$ after M phase.
- $G_1$: 16 chromosomes, $2C$.
- After S and in $G_2$: 16 chromosomes (32 chromatids), $4C$.
- Metaphase: 16 chromosomes, 32 chromatids, $4C$.
- Anaphase: 32 chromosomes, $4C$.
- After M phase: 16 chromosomes, $2C$, in each daughter cell.
:::

## Meiosis count table

For a diploid meiocyte with $2n$ chromosomes and $2C$ DNA in $G_1$. After meiosis I, values are **per cell**.

| Stage | Chromosomes | Chromatids each | DNA |
| --- | --- | --- | --- |
| $G_1$ (before S) | $2n$ | 1 | $2C$ |
| $G_2$, leptotene | $2n$ | 2 | $4C$ |
| Zygotene to diakinesis | $2n$ ($n$ bivalents) | 2 | $4C$ |
| Metaphase I | $2n$ ($n$ bivalents) | 2 | $4C$ |
| Anaphase I | $2n$ ($n$ to each pole) | 2 | $4C$ |
| After meiosis I (dyad) | $n$ | 2 | $2C$ |
| Prophase II, metaphase II | $n$ | 2 | $2C$ |
| Anaphase II | $2n$ ($n$ to each pole) | 1 | $2C$ |
| After meiosis II (tetrad) | $n$ | 1 | $C$ |

:::formula{title="Bivalent arithmetic"}
- Number of bivalents from zygotene to metaphase I $= n$ (none yet in leptotene).
- One bivalent = **2** homologous chromosomes = **4** chromatids = **2** centromeres.

A cell with $2n = 24$ forms 12 bivalents, with 48 chromatids in all.
:::

:::formula{title="Cells made (counting aid, not an NCERT formula)"}
$$1 \text{ meiocyte} \to 4 \text{ haploid cells}$$
$$k \text{ mitotic rounds: } 1 \text{ cell} \to 2^k \text{ cells}$$
The $2^k$ rule holds only if every cell divides in every round. $N$ haploid cells need $N/4$ meiocytes (one meiosis each), but only when all four products count. A primary oocyte gives just **one** egg (the rest are polar bodies; Class 12), so $N$ eggs need $N$ meiocytes.
:::

## Key terms

| Term | Meaning |
| --- | --- |
| Karyokinesis | Division of the nucleus |
| Cytokinesis | Division of the cytoplasm |
| Centromere | Point that holds the two sister chromatids together |
| Kinetochore | Small disc on the surface of a centromere where spindle fibres attach |
| Aster | Microtubules radiating from each centrosome |
| Metaphase plate | Plane where chromosomes line up at metaphase |
| Cell plate | First precursor of the new wall in a dividing plant cell; becomes the middle lamella |
| Syncytium | Many nuclei in one cytoplasm, because cytokinesis did not follow karyokinesis |

| Term | Meaning |
| --- | --- |
| Synapsis | Pairing of homologous chromosomes (zygotene) |
| Synaptonemal complex | Structure that forms along synapsed homologues |
| Bivalent (tetrad) | A synapsed pair of homologous chromosomes |
| Recombination nodule | Site where crossing over happens (pachytene) |
| Recombinase | Enzyme of crossing over |
| Chiasmata | X-shaped points where homologues stay joined (diplotene) |
| Terminalisation | Chiasmata moving towards the chromosome ends; marks diakinesis |
| Dyad | The two cells formed after meiosis I |
| Interkinesis | Short gap between meiosis I and II; no DNA replication |
| Tetrad of cells | The four haploid cells after meiosis II |
