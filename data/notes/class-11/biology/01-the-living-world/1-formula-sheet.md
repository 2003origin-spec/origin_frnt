## The four basic processes of taxonomy

:::formula{title="Taxonomy rests on four processes"}
**Characterisation, identification, classification and nomenclature.**

NCERT lists these four; it does not give them as a fixed sequence. It does say naming is possible only after correct identification.

- **Identification:** describing an organism correctly, so we know which organism a name belongs to.
- **Classification:** grouping things into convenient categories based on easily observable characters.
- **Nomenclature:** giving each organism a standard name, used all over the world.
:::

:::formula{title="Taxonomy and systematics"}
- **Taxonomy:** classifying organisms into different taxa based on their characteristics.
- **Systematics:** the study of the kinds and diversity of organisms **and the relationships among them**. It takes **evolutionary relationships** into account.

"Systematics" comes from the Latin *systema* (systematic arrangement). Its scope was later enlarged to include identification, nomenclature and classification.
:::

:::formula{title="Taxon (plural: taxa)"}
A group or category of organisms at any level, used as a unit of classification. Each taxon represents a **rank**.

"Plants", "mammals", "wheat" and "dogs" are all taxa, but at different levels.
:::

:::formula{title="Basis of modern taxonomy"}
- External and internal structure
- Structure of the cell
- Development process
- Ecological information
:::

## Naming: binomial nomenclature

:::formula{title="Binomial name = genus + specific epithet"}
Given by **Carolus Linnaeus**. Example: *Mangifera indica* (mango).
- *Mangifera* = genus
- *indica* = specific epithet
:::

:::formula{title="The codes"}
| Organisms | Code |
| --- | --- |
| Plants | ICBN (International Code for Botanical Nomenclature) |
| Animals | ICZN (International Code of Zoological Nomenclature) |

The codes make sure each organism has **only one** name, and that the name is not used for any other known organism.
:::

:::formula{title="Rules for writing a scientific name"}
1. Names are generally Latin or Latinised, and printed in *italics*.
2. First word = genus. Second word = specific epithet.
3. Handwritten: underline **each word separately**.
4. Genus starts with a **capital** letter. Specific epithet starts with a **small** letter.
5. The author's name comes **after** the specific epithet, in short form.

Example: *Mangifera indica* Linn. means Linnaeus first described this species.
:::

## The taxonomic hierarchy

:::formula{title="Ascending order (species to kingdom)"}
**Species → Genus → Family → Order → Class → Phylum (Division in plants) → Kingdom**

Going up:
- the number of **common characters decreases**;
- it gets **harder** to work out how a taxon is related to other taxa at the same level.

**Species** is the **lowest** category for all organisms.
:::

:::formula{title="What each rank groups"}
| Rank | Is a group of related |
| --- | --- |
| Genus | Species |
| Family | Genera |
| Order | Families |
| Class | Orders |
| Phylum / Division | Classes |
| Kingdom | Phyla (animals) or divisions (plants) |
:::
